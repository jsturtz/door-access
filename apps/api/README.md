# API Portal

We use [Nest](https://github.com/nestjs/nest) as our server backend

## Project setup

```bash
$ npm install
```

## Compile and run the project

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```

## Run tests

```bash
# unit tests
$ npm run test

# e2e tests
$ npm run test:e2e

# test coverage
$ npm run test:cov
```

## Lint with oxlint

```bash
$ npm run lint
```

## Format with prettier

```bash
$ npm run format
```
